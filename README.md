# 🎮 Higher Lower Game

A simple command-line Higher Lower game built with Python.\
The player must guess which footballer has more social media followers.

------------------------------------------------------------------------

## 🧠 Game Description

Two footballers are shown on the screen.\
You must guess who has more followers. If your guess is correct, your
score increases and the game continues. If wrong, the game ends.

------------------------------------------------------------------------

## 🚀 Features

-   🎲 Random player selection\
-   🔁 Continuous game loop\
-   🏆 Score tracking system\
-   🚫 No duplicate comparisons\
-   🎨 ASCII logo display

------------------------------------------------------------------------

## 🛠️ Technologies Used

-   Python 3\
-   Built-in `random` module

------------------------------------------------------------------------

## ▶️ How to Run

1.  Make sure Python 3 is installed.
2.  Save the file as `higher_lower.py`
3.  Run the game:

``` bash
python higher_lower.py
```

------------------------------------------------------------------------

## 🎯 How to Play

-   Type **A** if you think Compare A has more followers.
-   Type **B** if you think Compare B has more followers.
-   Correct answer → Score increases.
-   Wrong answer → Game over.
